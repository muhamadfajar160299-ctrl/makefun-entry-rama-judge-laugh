Entry for the make.fun competition [Make the AI Judge Laugh](https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825): one original joke about office life, a single line under 200 characters.

## How it works

`main.py` (Python standard library only) reads `entry.txt` next to it and writes it verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The entry is validated before writing: it must be non-empty, a single line, and at most 200 characters.

## Run

```sh
python3 -S main.py
```

## Files

- `main.py` — the entry program
- `entry.txt` — the one-line office joke
